# Langkah-Langkah

## INSTALASI PYTHON


### LINUX 
- TEKAN CTRL + ALT + T SECARA BERSAMAAN
- KETIK COMMAND BERIKUT DI TERMINAL DENGAN MENEKAN CTRL + SHIFT + V
  ```
  sudo apt update & sudo apt install python3
   ```
- KETIK COMMAND BERIKUT DI TERMINAL UNTUK MEMASTIKAN PYTHON TERLAH TERINSTALL
  ```
  python --version
  ```
- JIKA PYTHON SUSKES TERINSTALL MAKA AKAN TERTULIS VERSI PYTHON YANG TERINSTALL DI TERMINAL

### WINDOWS
- BUKA WEBSITE RESMI PYTHON [Python.org](https://python.org)
- KLIK MENU DOWNLOAD DAN PILIH WINDOWS
- PILIH STABLE RELEASE
- SETELAH BERPINDAH HALAMAN SCROLL SAMPAI PALING BAWAH DAN PILIH WINDOWS INSTALLER
- DAN JALANKAN FILE EXE NYA SEPERTI BIASA
- IKUTI PANDUAN NYA
- BUKA CMD DENGAN MENEKAN WINDOWS + R DAN KETIK CMD
- KETIK COMMAND ```
  python --version ```
  Untuk memastikan python telah terinstall

## MENJALANKAN PYTHON

### LINUX (UBUNTU/DEBIAN)
- BUKA FILES DAN BUKA FOLDER UNTUK MENYIMPAN FILE PYTHON ANDA
- BUAT FILE PYTHON ANDA DENGAN CARA : MENEKAN KLIK KANAN > CREATE NEW DOCUMENT > NEW DOCUMENT > MASUKKAN NAMA FILE DENGAN AKHIRAN .py CONTOH ``` contoh.py```
- BUKA FILE YANG BARU ANDA BUAT DENGAN CARA DI KLIK 2X
- MASUKKAN CODINGAN ANDA DI SANA CONTOH : ``` print("Hello World")``` LALU TEKAN CTRL + S UNTUK SAVE
- BUKA TERMINAL DENGAN CARA TEKAN CTRL + ALT + T
- KETIK ``` cd "home/username_anda/folder_tempat_file_anda" ``` DI TERMINAL ANDA
  CONTOH : ``` cd "/home/rennaraera/Documents/laprak/STUDI-KASUS" ```
- KETIK ``` python namafile.py ``` UNTUK MENJALANKAN FILE PYTHON ANDA CONTOH : ``` python contoh.py``` MAKA FILE ANDA AKAN DI JALANKAN

### WINDOWS
- TEKAN WINDOWS + R DAN KETIKAN CMD UNTUK MEMBUKA CMD
- (OPSIONAL) ANDA BISA MENGGUNAKAN COMMAND CD SEPERTI DI LINUX UNTUK MENENTUKAN FOLDER ANDA
  CONTOH ``` cd "C:\Users\NamaUser\Documents" ``` 
- KETIK ``` notepad namafile.py ``` UNTUK MEMBUAT FILE PYTHON ANDA (SEBUAH NOTEPAD AKAN OTOMATIS TERBUKA)
- MASUKKAN CODINGAN ANDA CONTOH : ``` print("hello world") ```
- KEMBALI KE CMD DAN KETIKKAN ``` python namafileanda.py ``` MAKA FILE ANDA AKAN DI JALANKAN
